# FITLOG 

> **Train with intent. Log every set.**

FITLOG is a dark, no-nonsense gym companion app designed to help you discover exercises, learn proper lifting techniques, and build custom daily training plans.

---

## Features

- **Workout Library**: Browse a collection of exercises targeting major muscle groups (Chest, Back, Arms, Legs, Shoulders, Core)[cite: 1, 2].
- **Exercise Instructions**: Detailed step-by-step guides, required equipment, difficulty levels, and target muscle breakdowns[cite: 1].
- **Custom Plan Builder**: Effortlessly add exercises to your daily plan or save them for later[cite: 1].
- **Workout Analytics**: Monitor total exercises, estimated workout duration (in minutes), and projected calorie burn ($kcal$)[cite: 1, 2].
- **Modern Dark UI**: Clean interface built with high-contrast accent colors for easy reading during workouts[cite: 1, 2].
